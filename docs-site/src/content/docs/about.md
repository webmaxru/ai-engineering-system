The AI Engineering System is the specification and learning repository for a
practical approach to agent-assisted software delivery. It defines the
responsibility boundary, contracts, evidence model, risk routing, and review
practice around the central principle:

> Agents propose; humans and policy accept.

## Source repository

The complete source, change history, and contribution guidance are available
in the [AI Engineering System GitHub repository](https://github.com/webmaxru/ai-engineering-system).

## Relationship to Northstar

This repository describes what the system is and why it is designed this way.
The [Northstar reference implementation](https://github.com/webmaxru/northstar-orders-api-demo)
demonstrates whether the system works end to end.

The documentation site is a presentation and publishing surface. It does not
replace the repository documents, GitHub reviews, workflow evidence, or human
acceptance.
